Overview

Lattice Systems is my open-source small language model line — from a 42M-parameter model built from scratch to a 1.5B conversational fine-tune. Both models are research demos, not production AI.

The Models

Lattice Mini

Lattice Mini is a from-scratch 42M-parameter GPT I built from the ground up and host on Hugging Face.

Lattice Pulse

Lattice Pulse is a conversational model fine-tuned from Qwen2.5-1.5B-Instruct — the second model in the Lattice Systems line.
